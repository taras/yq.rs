# napi-rs license sources

These MIT license texts come from the repository root at the commits recorded
in the corresponding crates' `.cargo_vcs_info.json`. The published Cargo
archives omit them. `.github/release/native.py` copies the matching text into
each platform package and fails if a dependency update lacks a matching text.

Source: https://github.com/napi-rs/napi-rs (each filename is its commit SHA).
